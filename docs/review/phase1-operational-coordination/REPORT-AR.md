## 4. ربط الكتّاب بما يثبت تشغيلهم

لا يعاد بناء سجل W/T المقبول. تستكمل لكل صف ناقص السلسلة: **كاتب/تريغر في المرجع الثابت → caller محدد → إصدار الخدمة/التطبيق → بيئة ودور → أثر طلب/تشغيل محفوظ → حدود المعاملة والمصالحة**.

- W04/dispatch_tick: التعريف والاستدعاء موجودان؛ جدولة وتشغيل Job مستقل غير مثبتين.
- W12: قبول الربط يذكر احتمال استمرار المسار عند ابتلاع خطأ حدث الوصول؛ لا يعد نجاح المسار إثباتاً لاكتمال كل أثر.
- W18 هو مسار الأمر المالي المقروء؛ W20 القديم يرفض request_id_required في اللقطة. وجود الاسم القديم لا يثبت أنه كاتب فعّال.
- W38..W49 و T24..T37 توسعة لعائلات مداخل/تريغرات، وليست 49 خدمة منشورة.
- R05 يثبت خصائص 173 دالة، 58 علاقة ضمن r/p/v، 332 تريغراً، 60 سياسة و 291 علاقة اعتماد كتالوجية في قراءات مستقلة؛ لا يثبت تطابق أجسام الدوال أو حصر SQL الديناميكي أو التشغيل الفعلي.
- لكل كاتب: يلزم caller boundaries ومواضع catch/savepoints و SQL المتعدي وأي أثر بعد COMMIT إن وجد، وآلية retry/idempotency ومصالحة الأثر. تصنيف EXTERNAL=N/A يحتاج دليلاً؛ UNKNOWN لا يتحول إلى INTERNAL بالافتراض.
- في PHASE1 نطلب **دليل قابلية الإيقاف والتصريف**؛ لا ننفذ pause/drain الآن. الإيقاف الفعلي وتجربة الانتقال في المرحلة 4 وفق الخطة.

B02/B03/B07 تبقى مانعة. المورد: المبرمج الرئيسي يجمع مراجع كل مشغل و DB؛ المراجع المالي/الأمني يحكم على اكتمال السلسلة. لا تكليف بناء outbox أو تغيير scheduler بهذا السجل.

## 8. الاعتمادات والتكليف التالي

**الخطوة التالية ضمن التنسيق الحالي، دون طلب تفويض مكرر:** المبرمج الرئيسي يحدد مراجع الأدلة الموجودة لدى حاملي النشر و API والمفاتيح والنسخ و CI في القنوات الخاصة، ويربط كل منها بـ B02..B09/R01..R11 أعلاه. المستشار يقرأ المورد المحدد ضمن تفويضه القائم حيث تنطبق شروطه ويصدر حكماً على الدليل الجديد فقط. لا طلب إعادة تسليم 49 أو أسرار أو إنشاء حسابات. المسؤوليات هنا أدوار لتوفير الدليل؛ لم يثبت وجود شخص منفصل لكل دور أو وصوله، ويجب تسمية المنفذ الفعلي في تكليف التنفيذ.

إذا لم يجد المسؤول دليلاً موجوداً، يسجل: المرجع الذي بحثه، والحقل الناقص، والقدرة التي يحتاجها. لا يحوّل عدم العثور إلى نفي خدمة أو إلى إذن إنشاء دليل تشغيلي.

**التكليف الذي يحتاج موافقة منفصلة، عند اكتمال اعتماداته:** حزمة تحقق فعلية محددة البيئة والمصدر والهوية والسيناريو لإنتاج الأدلة غير الموجودة؛ تبدأ فقط في موضعها الأصلي من الخطة. تشمل الموافقة بالضبط أي جلسة جديدة أو طلبات HTTP/RBAC أو Storage أو استعادة أو حقن أو حمل، وميزانيتها وحدودها ومخرجاتها. هذه بطاقة تكليف لاحقة، وليست سؤال موافقة الآن أو تفويضاً تلقائياً.
