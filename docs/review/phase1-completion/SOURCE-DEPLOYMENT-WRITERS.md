## طريقة قراءة الربط المستلم

هذا تحديث **لنفس W01..W37** مع حفظ معانيها؛ أضيفت W38..W49 لعائلات كتّاب كشفتها الأصول، و T24..T36 للتريغرات والحراس المتصلة. المصدر العام ثابت عند 611b0eb ؛ حزمة ماقبلالتحديث عند ab9794f. قبول P1-QA-01 و PC-QA-01 محفوظان؛ التفريع A01/A02 أعلاه بلا تغيير. مرشح 106 مقبول معزولاً وغيرمرحّل في لقطة 107.

المراجع التالية **ملفات خاصة مستلمة** ضمن AUDIT107 ؛ ليست روابط عامة إلى الخام. كل selector يختار صفاً في JSON ثم حقوله، لا رقم صف في قاعدة حية:

- `R/D/P(oid)` = `target-routines.json[oid=…]` (schema/name/args/arguments/result/security_definer/owner/proconfig)، و`target-definitions.json[oid=…].definition`، و`target-function-privileges.json[oid=… AND role=…]` (schema_usage/can_execute). جميع الأربعة anon/authenticated/authenticator/service_role مفحوصة للمنح الملخصة؛ SD=SECURITY DEFINER ، U+E=منحة USAGE و EXECUTE في الكتالوج **ليست إذناً وظيفياً أو إثبات HTTP**.
- `TT(oid)` = `target-triggers.json[oid=…]` مع function_oid ثم D ؛ `TT(relation=…)` يقيد schema أيضاً. enabled=O في التريغراتغيرالداخليةالمشارإليها؛ لايثبت session_replication_role لكل طلب.
- `REL/EF/POL/QC/IX/COL` = target-relations/target-effective/target-policies/target-constraints/target-indexes/target-columns.json ؛ selector الجدول = schema+relation (وفي REL schema+name)، ثماسم column/constraint/policy/index والـ role عنداللزم. `QA` هنا اختصارملف `target-additional.json[0]` وليسحكم QA.
- `DEP(oid)` = target-dependencies.json[class=pg_proc AND objid=…]؛ رُبطت أيضاًصفوف class=pg_trigger بالـ TT.function_oid والعلاقات/القيود. هذه حوافكتالوجيةلا تحصر SQL داخل PL/pgSQL ؛ لذلك استُخدمت الأجسام والتريغرات والسياسات معاً. `writer-scan.json[oid=…]` قرينةمساعدة فقط: مثلاًقائمته writes لا تعرض INSERT ratings لـ rate_order أو order_offers لـ dispatch_tick رغموجودهافي D.
- نطاقاللقطة ووقتها ودرجاتالاختلاف من إغلاق[107](https://github.com/merapplications-sketch/Talabat-v3/blob/60bbc90d4c8d03311464be049063d0fac3ae18f1/docs/review/continuation107/REPORT-AR.txt): 2026-11-10 14:39:27–14:57:52UTC ؛ هدفمعزول PG17.11 ؛ التقاطغيرذري. لااستعلامجديد ولاحكمبانتفاءخدمةخارجالكتالوج.
- **DB/caller**: الجسم والتريغراتالمتزامنة ضمنمعاملةالمستدعيحسبالبنيةالمقروءة؛ لا COMMIT داخليفيالمداخل المذكورة. هذا **ليس نجاح rollback/ACK/restore**؛ سياسةالمستدعيالعليا/عزل request/gateway/التقاطالاستثناءاتالخارجية UNKNOWN. عدموجود explicitlock لايعنيانعدامأقفال DML. لا تسلسلأقفال شامل أوعدم deadlock مثبتمنالنص.
- الجداولالمذكورة تحمل FK/constraints مقروءةفي QC ؛ الحذفيمكنأنيشغّل cascade/SET NULL حسبالقيد. آثار trigger مرتبطةبنوعالحدث وشروط body ؛ لا يفترضتشغيلكل triggers علىكل UPDATE. الآثارالخارجيةالمادية(نقد/تحويل/تسليمالوجبة/رفع object) ليستضمن SQL ؛ لا outbox أو dedup خارجي مثبت.

## المالية: الفصل بين داخل المعاملة وخارجها

لكل W/T المصدر يثبت فقط الكتابات المتزامنة الظاهرة داخل معاملة المستدعي. لا يثبت أن خدمة مستدعية تجمع عدة RPC في معاملة واحدة، ولا استبعاد callbacks/Jobs/HTTP خارج الأجسام والكتالوج المحدد المقروء. لم يظهر اتصال HTTP خارجي في المسارات المالية المقروءة؛ ذلك ليس حصراً لجميع الخدمات. المالالمادي/التحويل الخارجي ليس داخل SQL.

## ضوابط قراءة النتائج والمصالحة

- الأثر الداخلي المتوقع بنيوياً قد لا يكون إلزامياً عند وجود EXCEPTION handler: W12 يبتلع فشل INSERT حدث الوصول؛ W26/W38 يعيدان بعض أخطاء التسعير/العرض كبيانات ويكتبان سجل المحاولة حسب الفرع؛ W01 يعالج unique_violation. لا نعلن ذرية جميع الآثار المطلوبة أو نجاح التراجع من النص وحده.
- أنواع الفهارس المقروءة مهمة: ratings_pkey على order_id ؛ loyalty_one_reward/earn/return_per_order على lots ، بينما ledger لا يحمل هذه الفهارس نفسها؛ wallet_one_spend/return/cashback_per_order و wallet_one_refund_per_ticket. المرجع IX باسم index_name ؛ لا نستنتج تكراراً فعلياً أو ننشئ فشلاً للاختبار هنا.
- W16: قيد مرجع refund/command يمنع تعارضاً داخل DB وفق جسمه، ولا يمنع تحويل نقد خارجي مكرر وحده. W18: request/result/receipt داخل DB ، و W19 يقرأالنتيجةالأصلية؛ الإثبات الخارجي لاستلامالنقد ومصالحة ACK/restore ما زال B07. لا outbox/receiver-idempotency مفترض.
- EF(profiles,authenticated).can_update=false لا ينفي منح الأعمدة في QA.column_acls ؛ و EF(stores,authenticated).can_select=false لا ينفي SELECT للأعمدةالمسموحة. تُقرأ RLS و column grants و guards معاً. لا قبول RBAC مستضاف من ACL.
- A01 من AUDIT107 باقٍ: authenticated يملك TRUNCATE على order_items في اللقطة؛ anon لا. لا تنفيذ أو إثبات منفذ HTTP أو تعديلمنح. أي منح أخرى مرئية في EF ليست إذناًلاختبارها ولا حكماًبوقوعاستغلال.
- DEP الخاص بالدوال الأساسية يحمل حوافاً كتالوجية لا كامل استدعاء PL/pgSQL ؛ body+D/R/TT/P/QC/POL هي سلسلة الإسناد. لا يُعاد بناء fixture ولا يُعلن حصر كل كاتب موثوق/service_role/owner أوخدمةخارجية.
