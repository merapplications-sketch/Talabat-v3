هذه16 حالة عقدية، وليست16 اختباراً ناجحاً. بعض الحالات حسابات عددية دقيقة، وبعضها شروط أو علاقات رمزية. لا تُعد النتيجة مرجعاً خارج شروط صفها. لا نسبة أو تعرفة جديدة، ولا نتيجة من البرنامج المرشح أو fixture. الأرقام25/15/5 و0 من أمثلة CASH-01، ومعدلات الولاء من القرارات المحفوظة، وبقية مبالغ الطعام أمثلة اصطناعية معلنة.

يحتوي EXPECTED-RESULTS.json على المدخلات والخطوات والشروط والحدود بصيغة قابلة للاستخدام في اختبار مستقبلي مخوّل. الأرقام العشرية محفوظة كنصوص؛ لا تنفيذ API أو قاعدة بيانات أو ملفات الأدلة.

## اشتقاق تشخيصي مشروط G1C-PREC-03، خارج الحالات المقبولة أعلاه

القيمة الاصطناعية paid=12.00000001TJS مع معدل الكسب المعتمد10 تعطي بدقة عشرية:
12.00000001×10=120.0000001.
قاعدة الأعمال «التقريب للأعلى» تعطي121 نقطة.
التعبير المقروء في trg_loyalty يطرح0.000001 أولاً:
120.0000001−0.000001=119.9999991؛ وتقريبه للأعلى يعطي120.
لم تُشغّل الدالة لإنتاج الرقمين. هذه مقارنة حسابية مستقلة لتعبيرين.
لا تُقبل الحالة كاختبار تشغيل قبل إثبات أن عقد إدخال السعر/المدفوعات يسمح بهذه الدقة. وجود numeric غير المقيد لا يثبت وحده مسار HTTP أو قبول القيم. إن قُيد المجال بقرار موثق يستبعدها، يعاد تقييم الفجوة؛ لا تُغيّر قاعدة الكسب المعتمدة تلقائياً.

## حدودnumeric(12,2)

السعة التمثيلية ذات10 خانات صحيحة ومنزلتين تعطي الحد العشري9999999999.99؛ هذا حد نوع، وليس سقف منتج معتمداً.
التحويل عند التخزين ليس سياسة تجارية تلقائية؛ يلزم حسم رفض/تقريب مدخل زائد الكسور، والإشارة، والفيض، وNULL والقيم غير المنتهية بحسب المسار.
orders/receipts.amount في اللقطة ليست جميعها12,2؛ لا تعميم لنوع wallet_entries.amount على باقي المنظومة.
