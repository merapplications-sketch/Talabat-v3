- قرار المالك الجديد يحسم مجال الإكرامية للإنشاء الجديد: صفر عند عدم الاختيار، أو عدد صحيح من 1 إلى 100 TJS شاملاً؛ الخيارات السريعة 5/10/20؛ كامل الإكرامية للسائق. الكسور والسالب وما فوق 100 غير صالح.

- المرحلة1 غير مكتملة؛ المرحلة2 NO-GO. هذه مراجعة عقد، وليست نتيجة PostgreSQL أو HTTP أو تجربة واجهة.

## 3. الفصل بين API الأصلي والسياسة المعتمدة

1. نوع p_tip في المداخل المقروءة numeric وقيمته الافتراضية 0. عند استدعاء يحذف هذا المعامل ويستخدم التوقيع نفسه، تصبح قيمته 0. هذا عقد مصدر؛ لم نثبت هذه الرحلة عبر HTTP المستضاف في هذا التكليف.
2. تمرير SQL NULL صراحةً لا يشغّل DEFAULT 0. الجسم السابق يحوّل القيمة المخزنة إلى0 عبر CASE، لكنه يكوّن payload للبصمة باستخدام p_tip الأصلي قبل ذلك. هذا يشرح السلوك السابق ولا يعتمد سياسة NULL للإنشاء الجديد.
3. محوّل العميل الأصلي o.tip||0 قد يحوّل null/undefined وبعض القيم falsy إلى0 قبل RPC. لذلك لا يكفي اختبار UI وحده لإثبات تمييز API، ولا يجوز الاستناد إلى truthiness لقبول مدخل غير صالح.
4. HMACv1 يزيل الفروق العددية غير المؤثرة في scale:20 و20.0 متكافئان كقيم numeric. NULL و0 مختلفان. التطبيع الخاص بـNULL/{} ينطبق على extra وحده.
5. لا يعاد توليد بصمة طلب قديم من orders.tip؛ قد تختلف القيمة المخزنة عن الإكرامية التي حمتها البصمة. لا إعادة تسعير أو تعديل تاريخي ضمن TIP-02.
6. اعتماد مجال جديد لا يجيز تغيير نوع التوقيع أو HMACv1 أو ترتيب التفويض والأقفال أو العقود المالية. API encoding/coercion يراجع كعقد تقني عند المصدر النهائي، ولا تُستنتج نتائج HTTP من numeric في SQL وحده.

- تطابق المفتاح بين الأجهزة يحميه الخادم؛ جهازان يصنعان مفتاحين مستقلين لا يثبتان نية واحدة. لا ادعاء أن IndexedDB يوفر حماية مشتركة بين الأجهزة.

## 6. الفجوات الحقيقية ومسؤول إغلاقها

## 7. أثر القرار على TIP-A..G

- TIP-A: يتوسع عقد القيم الجديدة إلى0 و1..100؛ القبول التنفيذي الجديد ينتظرTIP-02.
- TIP-B وTIP-C: قبولTIP-01 محفوظ؛ معايير عدم التراجع للقديم وHMACv1 لازمة عند تغير الحارس، دون تغيير السياسة التاريخية.
- TIP-D: حماية المحاولة/التبويبات والسلة متأثرة بإضافة Other؛ الاختبار الفعلي غير منفذ هنا.
- TIP-E: حواجز106 والرجوع محفوظة؛ لا قبول جديد بمجرد الوثيقة.
- TIP-F: أثر المصدر معروف ضمن حدوده؛ الرحلة الفعلية والاسترداد والعقود الناقصة لا تُغلق بهذا القرار.
