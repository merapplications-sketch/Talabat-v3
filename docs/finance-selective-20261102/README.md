## ما بقي وما هو مستقل

**أُزيل مانع تكييف المصدر**؛ المرشح محدد ومفحوص ضمن الحدود أعلاه، ولم ينشر. الموانع المتبقية لفتح الإصلاح: قبول Safari لدى الفريق، موافقة نافذة الخادم/النشر/التفويض، وتحقق فرق الحالة وقت النافذة ونسخ البيانات اللازمة. إنشاء «محاسب TALABOT» **معلق على بيانات اتصال حقيقية**؛ لا حساب جديد أو UUID أو تفويض مالي الآن. يمنع غياب الحساب فتح الكتابة للمحاسب، ولا يمنع مراجعة المرشح أو الاختبارات المعزولة. تغيير اسمه لاحقاً لا ينقل الحساب لشخص آخر؛ يبقى UUID وإسناد الحركات التاريخية لصاحبها.

**مرحلة مستقلة وغير مكتملة:** إيصال التسوية وإقرار الطرف الآخر، دفتر الصرف ودليل الدفع وصافي المستحقات، والتنبيهات الدائمة. لا تُستخدم لتعطيل إصلاح القراءة والقفل والإسناد الحالي، ولا يُدعى اكتمالها. سجل commands ليس إيصال تسوية مستقلّاً.

لم تطبق هذه الجولة SQL حياً أو رقعة خادم أو تفويضاً أو حركة مالية أو نشراً أو دمج main، ولم تُنشئ حساباً. لا يحتاج استكمال التحضير التقني إلى تكليف المالك باختبار أو جمع سجلات.
