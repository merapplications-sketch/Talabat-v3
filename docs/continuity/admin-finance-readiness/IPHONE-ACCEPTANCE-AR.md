# تجربة iPhone — إصلاح الإدارة والمالية

## تجربة جاهزة الآن، دون خادم أو حساب حي

افتح `iphone-isolated-preview.html` كمعاينة HTML تفاعلية في بيئة عرض تدعم JavaScript. الملف كامل ومعزول، وبأعلاه وسم روسي دائم: «ДЕМО · ТОЛЬКО ИСКУССТВЕННЫЕ ДАННЫЕ». الأسماء والأرقام والأرصدة وحالات النجاح/الفشل اصطناعية، وليست قراءات من المشروع.

القائمة العلوية تختار: تاريخ السائق على عقد جديد، محفظة، فشل قراءة مع بيانات سابقة، نتيجة غير محسومة، أو خادم قديم يرفض التنفيذ. كل نقر على الحركة يحاكيها داخل الصفحة فقط. CSP يمنع الاتصال الخارجي، وإعدادات Supabase ومفتاحها مستبدلة. لا تسجيل دخول حقيقي ولا دفع أو رفع.

بعض عوارض ملفات iOS/Quick Look لا تشغّل JavaScript؛ ظهور نص الملف أو فراغ هناك ليس حكماً على التطبيق. لتجربة Safari فعلية يمكن للمراجع تشغيل الملف من خادم HTTP محلي على حاسوبه والوصول إليه من الهاتف على الشبكة نفسها، دون نشر إنترنت. مثال تشغيل محلي في مجلد الملف: `python3 -m http.server 8791 --bind 0.0.0.0`. عنوان IP المحلي لا يمكن تحديده من هذه الجلسة، ولم يبدأ خادم عام أو يُنشر رابط خارجي.

## قائمة قبول جهاز فعلي — كلها OPEN

| الحالة | المطلوب ملاحظته | ما لا يثبته الملف |
|---|---|---|
| تاريخ السائق مباشرة | الاسـم/التوقيت/المرجع مقروءة؛ لا تداخل عند تمرير Safari وإظهار شريطه | وصول قراءة حيّة من الخادم |
| فشل القراءة وإعادة المحاولة | التحذير مقروء وزر المحاولة لا يغطي الحركة السابقة | انقطاع شبكة Supabase الحقيقية |
| المحفظة والكيبورد | إدخال موجب/سالب وكسور TJS وسبب روسي؛ اللصق وتبديل لوحة المفاتيح؛ الأزرار قابلة للوصول بالتمرير | نجاح تعديل مالي حقيقي |
| الرجوع والتدوير | بقاء المدخلات وعدم تغطيتها بشريط Safari أو safe area؛ تجربة عمودي/أفقي | قبول جميع أدوار التشغيل |
| غير محسوم | الحالة واضحة وزر فحص النتيجة مفهوم؛ لا يتعامل المستخدم معها كإيصال | نتيجة مالية حية أو موافقة استلام |
| خادم قديم | التنفيذ المالي غير متاح بوضوح | أن هذا الملف هو الإصدار المنشور |

سجّل طراز الجهاز وإصدار iOS/Safari والتوقيت ووضع المتصفح، ولقطة شاشة بلا بيانات أشخاص. QA الموجود Chromium 133 بمقاس 390×844 و844×390 ولمس محاكى؛ لا iOS native keyboard ولا WebKit فعلي أُجري هنا.

## ما يتطلب إصداراً منسقاً لاحقاً

قراءات finance_* وإسناد أحداث تاريخية فعلي وتفويض محاسب فعلي تحتاج الرقعة والواجهة معاً. الحسابات الحالية بلا عضويات staff_members؛ لا تنشئ أو تفوض حساباً لمجرد إجراء التجربة دون تكليف صريح. قبل تطبيق الرقعة يمكن فقط تجربة الملف الاصطناعي وقراءات التطبيق المنشور الحالية بصلاحياته القائمة؛ لا يجوز وصف سلوك الملف بأنه تحقّق حي.

لا تختبر إيصالاً أو دفتر صرف أو تنبيهاً دائماً كميزة جاهزة؛ هذه بنود مستقلة غير مكتملة. لا عملية مالية حية ضمن هذا التكليف حتى لو أظهر الملف نجاحاً محاكياً.
