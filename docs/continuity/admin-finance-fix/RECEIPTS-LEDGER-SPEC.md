# مقترح مستقل: إيصال التسوية ودفتر الصرف والتنبيه

غير معتمد للتطبيق، ولا يغيّر قواعد مالية. رقعة B بنية مبدئية فقط.

## سجل الإيصال
مرجع UUID ثابت مرتبط بأمر idempotent واحد، اتجاه driver_to_office أو office_to_driver، مبلغ موجب بـTJS، السائق الطرف المقابل، المكتب جهة مؤسسية، الموظف المنفذ، وقت الخادم، والطلبات المرتبطة مع نسخة مبلغ كل طلب. لا يُستنتج إقرار الاستلام من مجرد إنشاء سجل؛ counterpart_ack_at اختياري يبقى null حتى تعتمد آلية الإقرار. لا ننسب تاريخياً حدثاً لموظف جديد ولا نبني إيصالات من 18 حدثاً.

عقد الترحيل المستقبلي المطلوب: يتحقق من تفويض المحاسب، يقفل المجموعة/المفتاح، يربط الإيصال بالطلبات الفعلية ويطابق المبلغ بمجموعها داخل المعاملة نفسها، ثم يسجل إشعاراً واحداً لكل مستلم/إيصال/نوع. في الصرف يُشترط مرجع موافقة وطريقة/إثبات معتمدين؛ لا يكفي وجود driver_payout. **هذا الكاتب غير موجود في B ولا تمثّل اختبارات DDL اختباره.** لا توصيل تلقائي لرقعة A قبل مراجعة القرارات.

## العرض المحاسبي المطلوب
| البند | مصدر الإثبات | ما لا يمثّله |
|---|---|---|
| نقد العملاء بحوزة السائق | cash_collected للطلبات غير المسوّاة | ليس صافي مستحق السائق |
| النقد المسلّم للمكتب | إيصالات driver_to_office وطلبات مرتبطة | أحداث audit مفردة ليست إيصالات |
| أرباح السائق المحتسبة | driver_payout للطلبات المعتمدة وفق القواعد القائمة | ليست مبلغاً مدفوعاً |
| المدفوع للسائق | دفتر disbursements مع إيصال office_to_driver وموافقة | لا ينشأ من الأرباح تلقائياً |
| المتبقي للسائق | أرباح مستحقة ناقص صرف مثبت، بعد اعتماد نطاق الاستحقاق | لا مقاصة تلقائية مع النقد بحوزته |

## التنبيه
تنبيه دائم للطرف المعني مرتبط بالإيصال، مرجع فريد يمنع تكراره عند إعادة الطلب؛ المحاسب يرى ما يحتاجه والسائق حركاته فقط. القراءة/المشاهدة لا تعني قبول الطرف المقابل. رقعة B تمنع كتابات العميل وتكرار المفتاح، لكن إنشاء التنبيه وتأشير القراءة وعرضه ينتظران عقد ترحيل وصلاحيات مراجعاً.

## قرارات مفتوحة محددة
1. هل القبض الجزئي مطلوب؟ A تواصل تسوية كامل المجموعة الحالية؛ B لا تفترض تقسيم مبالغ الطلب أو مسؤولية عجز.
2. طريقة اعتماد الصرف ودليل الدفع ومن يوافق ومن يسجل، وآلية إقرار الطرف المقابل. لا يُفترض أن الكاتب هو المستلم الفعلي دون دليل.
3. نطاق الأرباح المستحقة وتاريخ الإقفال ومعالجة التسويات اللاحقة، دون تعديل قاعدة العمولة القائمة.
4. هل يسمح بأي مقاصة بين نقد العملاء وأرباح السائق؟ لا تُنفذ دون قرار صريح.
5. كيف يُعالج السجل القديم: عرضه كما هو مع علامة نقص الإثبات، أو استكمال مراجع موثقة بإجراء مراجع. لا تعبئة تاريخية آلية.

لا تتطلب هذه القرارات إيقاف إصلاح أخطاء القراءة أو القفل أو إسناد المنفذ، ولا تُفعّل ماليات مجمدة.
