2. [المرجع الشامل](TALABOT-CONTINUITY-2026-11-01.txt): السياق والخطة والتصاميم والتاريخ والحسابات والبنود المفتوحة؛ ملف تاريخي محفوظ كما وصل، ويقرأ مع الاستدراكات الأحدث.
3. [سجل التسليم والتكامل](../driver-handoff/DRIVER-NOTES-2026-10-24.md)، خاصة §§48–49: أدلة وتقارير التنفيذ وتصحيح ما استجد بعد المرجع.
4. [خطة التوصيل والتتبع](../plan/DELIVERY-TRACKING-PLAN.md) مع السجل الأحدث، لا منفردة كتكليف جديد.

## قواعد الاستلام
- الروسية أساسية، TJS، الشعار الأصلي.
- القرار الأحدث الصريح يحدّث الأقدم في البند نفسه؛ سحب اللوحة ملغى.
- افحص HEAD والعمل الجاري قبل التنفيذ؛ لا تكرر عملاً محفوظاً.
- منفذ واحد لكل مهمة؛ لا تنفيذ موازٍ لنفس المطلوب لدى كلود وتشات.
- ميّز القرار عن الاقتراح، والكود عن الاختبار المحلي وعن قبول iPhone الحي.
- لا تغير الحسابات أو الخادم أو SQL أو الخدمات المدفوعة أو تنشر تلقائياً بناء على ملفات السياق.
- لا تعيد فتح تدقيق 9115/9116 أو فحوص ناجحة بلا تغيير مؤثر.
- أي اتفاق جديد يضاف مع تاريخ ومصدر وحالة ودليل، ويحدث هذا المدخل عند إضافة مرجع؛ لا يترك داخل محادثة وحدها.
- ضمان المشترك لمال السائق في طلباته المباشرة معتمد في الخطة؛ بقية تفاصيل الإلغاء وضمان طلبات السوق معلقة. لا تحول التوثيق إلى تغييرات مالية حية.
- خريطة استكشاف المطاعم للزبون وDine Out وحجز الطاولات والإعلانات، ومنها بعد إنهاء الطلب، ضمن الخطة. استرجع تفاصيل كلود السابقة قبل التنفيذ؛ لا تختزلها في التوصيل أو بانر الرئيسية.
