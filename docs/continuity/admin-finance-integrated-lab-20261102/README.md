## نوع الإثبات وحدوده

هذه ليست ردود RPC جاهزة: الواجهة تمرر أسماء الدوال ومعاملاتها إلى **PostgreSQL 17.5 الحقيقي المبني لـWASM، PGlite 0.3.14**. تُعاد بنية الكتالوج المحفوظ: 119 تعريف دالة أصلية، 36 جدولاً، enums والقيود والتريغرات والفهارس وRLS والمنح؛ ثم تطبق **رقعة A نفسها دون تعديل**. بصمتها `6c85e0419412986d8ca811d72206a674d8375530bcccf75dd34d3bc4128e0259`.

كل استدعاء يدخل معاملة PostgreSQL بـ`SET LOCAL ROLE authenticated` ومفتاح هوية اصطناعي لـauth.uid. التفويض يتم بدالة `staff_set` الأصلية، وليس بتبديل boolean في الواجهة. القبض وcommands وcash_settled_at وaudit وأسماء المنفذين كلها SQL فعلي. لا يعاد تشغيل فحوص A العامة أو اختبارات Chromium/WebKit السابقة؛ الإضافة هنا ربط واجهة المرشح بهذه الدوال الحقيقية.

**الحدود:** محوّل محلي بواجهة شبيهة بـsupabase-js، وليس خادم PostgREST أو GoTrue. auth.users بنية اصطناعية، والهوية محاكاة محلية؛ لا اختبار كلمات مرور أو تسجيل بريد/هاتف أو تحقق JWT مستضاف. المحرك WASM أحادي الاتصال وليس PostgreSQL 17.11 الأصلي أو خدمة Supabase كاملة؛ اختبارات التوازي/الأذونات السابقة تبقى ضمن بيئاتها. لا يعمم هذا الحكم إلى جاهزية إتاحة المال الحي أو Safari فعلي.

الواجهة في `web/admin-lab.html` مشتقة من المرشح: تهيئة اتصال المختبر فقط بدلاً من endpoint/key الأصليين، وحقن محوّل SDK المحلي، وتضمين JS/CSS الماليين، وإجبار لغة RU للمختبر، وCSP تمنع اتصال iframe بالشبكة. على HTTPS يستخدم العميل crypto.randomUUID الأصلي؛ في معاينة terminal.local عبر HTTP فقط توجد مواءمة UUID بـgetRandomValues، ولا تغير مصدر المرشح. بقية منطق الواجهة والنواة من المصدر المثبت.

## استخدام التجربة

هذه أزرار تجربة اصطناعية، وليست طلب مهام قبول تقنية من المالك:
1. «Дать ДЕМО бухгалтеру finance» يشغل staff_set من المدير الاصطناعي ويفتح حساب المحاسب المحدود.
2. «Открыть курьера»، ثم «Принять наличные» لتسوية 57.
3. «Новый заказ 43 TJS + потеря ответа»، ثم القبض من شاشة السائق؛ يظهر عدم الحسم، ثم «Проверить результат» لحسمه بالقراءة.
4. «Показать SQL-доказательства» يعرض صفوف القاعدة وسجل الاستدعاءات، ويمكن تنزيله. تحديث الصفحة ينشئ قاعدة اصطناعية جديدة مستقلة.

## الموانع المحددة والمتبقي

- استكمال Auth/REST المستضافين يتطلب بيئة Supabase مستقلة أو تشغيل كامل محلي عبر Docker. Docker غير متاح في المنفذ؛ ولم ينشأ مشروع سحابي لأن المالك لا يريد اشتراكاً. اختير المختبر المحلي داخل المتصفح بدلاً من مورد مدفوع. لا نحول أو نوقظ مشروعاً قائماً بديلاً.
- نشر المختبر الخاص نجح عبر أداة Sites، لكن المتصفح السحابي توقف عند بوابة ChatGPT. منعت المراجعة التلقائية محاولة متابعة تسجيل الدخول إلى auth.openai.com لعدم تصريح صريح بهذا الدخول. لم تُتجاوز البوابة، ولم يُطلب من المالك دخول المتصفح أو جمع أدلة. لذا قبول واجهة الرابط المحمي في متصفح فعلي غير مثبت هنا؛ قبول الربط المحلي منفصل وواضح.
- المعاينة المشتركة terminal.local تغيّرت إلى مشروع آخر؛ لم نوقفه أو نبدل محتواه. أُكمل الربط في DOM محلي دون الاعتماد على تلك المعاينة المشتركة.
- Safari/iPhone الفعلي وحساب المحاسب الحقيقي وقرار التفعيل ما زالت مفتوحة. A مطبقة **داخل المختبر فقط**، لا في المشروع الحي. لا تفويض مالي حي أو حركة حية أو نشر TALABOT أو main.

المصدر قابل لإعادة البناء بـ`npm ci` ثم `node build-schema.cjs` وبناء lab.js بواسطة esbuild. ملفات WASM/data تأتي من نسخة PGlite المثبتة في lockfile. `integration-dom.cjs` يختبر فجوة الربط فقط؛ لا يستدعي Supabase الحي. لا تعِد فحوصه الناجحة لمجرد الاستلام.
