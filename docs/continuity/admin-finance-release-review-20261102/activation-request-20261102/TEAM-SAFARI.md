# بوابة Safari — مسؤولية فريق التنفيذ/QA
الطلب: AF-ACT-20261102-01. المصدر الوحيد: `24a153c846ad1b122527e9245e1081dde4207930`.

الحالة **OPEN / EXECUTOR UNAVAILABLE**. لم يتوفر في هذه الجلسة جهاز Apple أو منفذ Safari للفريق؛ المتصفح المتصل Chrome والمنفذ Linux بلا WebKit. لا يوجد اسم مختبِر أو جهاز أو قناة حجز موثقة؛ لا ندعي إرسال المهمة لشخص أو تشغيلها خارج الأدوات المتاحة. حفظ هذا الملف تكليف وظيفي داخل المشروع، وليس نتيجة اختبار. الدليل في safari-environment.json.

الفحص المتبقي فقط، عند توفر Safari لدى الفريق:
- تشغيل المعاينة الاصطناعية المبنية من المرشح المثبت، مع منع شبكة المال الحي. يسجل المختبر الجهاز وإصدار النظام وSafari وبصمة المصدر.
- جلسة متصلة واحدة: ظهور unresolved ومفتاح الأمر، وسجل البداية execute=1/status=0/effect=1؛ خمس محاولات لمس على القبض المعطل قبل أي فحص؛ ثم فحص واحد.
- حفظ ترتيب الأفعال والسجلات قبل/بعد؛ مطابقة المفتاح في الأمر والإرسال وقراءة الحالة والنتيجة والأثر. بعد الخمس تبقى 1/0/1، وبعد الفحص تصبح 1/1/1، والأثر لا يتغير. يميز سجل الزيادة القراءات فقط عن أي finance_execute.
- يغلق البند فقط بوجود التسلسل على Safari المسجل. WebKit مكتبي وحده أو Chromium لا يغلق Safari الفعلي. جلسة جديدة لا تحسم جلسات قديمة بأثر رجعي.
- ترفق الأدلة بهذا الطلب في المستودع دون أسرار، ويحدث الحكم من الفريق. لا تطلب من المالك تسجيل شاشة أو تنفيذ خطوات أو جمع سجلات. لا تعاد فحوص Chromium أو البنود السابقة المغلقة.

غياب المنفذ يبقي البوابة مفتوحة ويمنع اعتبار طلب التفعيل جاهزاً للتنفيذ، لكنه لا يعيد فتح الإغلاقات المحفوظة أو يوقف مراجعة الطلب وبقية التحضير المستقل.
