أ. موقع السائق:
استخدم GEO الموجود في driver.html: state وlat وlng وacc، وwatchPosition/startGeo/stopGeo/pushGeo الحالية. لا تنشئ مراقب موقع ثانياً أو كتابة موقع جديدة من طبقة التصميم.
يحتاج مزود العرض حالة إذن/تحميل/خطأ، إحداثيات صالحة من الموقع الحقيقي، الدقة بالمتر وحالة حداثة القراءة. GEO لا يعرض timestamp القراءة حالياً؛ إن احتاج العرض عمر القراءة فوفّره من مصدر الموقع نفسه، ولا تعتبر GEO.sent وقت GPS؛ فهو وقت إرسال للخادم. لا نفترض مهلة حداثة جديدة.
لا تستخدم عنوان المطعم أو الزبون أو نقطة ثابتة كموقع سائق، ولا تحرك الرمز بمؤقت على أنه تتبع.
ب. المطاعم:
الحقول الموجودة في السجل: id وname وaddress وlat وlng وis_active وis_open. استخدم id مرجعاً ثابتاً، وافحص صلاحية الإحداثيات، ولا تعوّض الناقص بتحويل عنوان تلقائي أو نقطة وسطية.
TLB.stores(true) يشمل غير الفعّال أيضاً؛ لا تعرضه كله تلقائياً. حدّد السجلات المصرح بعرضها وفق صلاحيات التطبيق والقواعد الفعلية.
لا يوجد في عقد هذه الواجهة تعريف مثبت لنصف قطر «قريب». يحتاج كلود تأكيد مصدر قائمة القريب ونطاقها المسموح للعرض. لا تضع5km أو مسافة أو ترتيباً جديداً من التصميم، ولا تمس my_offers أو توزيع الأقرب أو مهلات العروض.
حالة empty لا تظهر إلا بعد نجاح طلب القرب وموقع صالح وقائمة فارغة. فقد الإذن أو الإحداثيات أو الربط حالة مختلفة؛ لا تصفها بعدم وجود مطاعم.
ج. الخرائط:
استخدم مزود Leaflet/OSM الحالي وصلاحياته وReferrer Policy التي أصلحها كلود. عالج تحميل البلاطات والفشل، وإعادة توسيط حقيقية، وملاءمة العلامات للمساحة المكشوفة بين الترويسة واللوحة.
قرب المطاعم للعرض لا يعني وجود طلب لديها أو أولوية توزيع. لا تُعرض مسارات أو ETA أو كثافة طلبات بلا بيانات معتمدة.
عند الانقطاع يمكن الاحتفاظ بآخر عرض معروف مع بيان قِدمه إذا وفر المصدر ذلك؛ لا توحِ بتحديث حي. لا تعتبر رمزاً خافتاً في المعاينة إثبات موقع سابق فعلي.
د. عقد عرض مقترح فقط، لا خدمة قائمة:
window.TALABOT_WAITING_MAP_UI اختياري ومطلوب ربطه بواسطة كلود. read() يعيد location: ready/loading/denied/error، nearby: ready/loading/empty/error/unbound، وmap: ready/loading/error/unbound من بيانات حقيقية فقط.
mount(node,{getLocation,onViewChange}) ينشئ طبقة الخريطة ويعيد update(viewState) وresize({visibleTop,visibleBottom}) وrecenter() وdestroy(). getLocation يقرأ GEO دون تعديله. onViewChange يُستدعى لتغير حالة بيانات مهم، وليس من كل resize أو حركة خريطة لتجنب حلقات الرسم.
هذا اسم مكوّن مقترح محلي، وليس endpoint أو API منشوراً. دون مزود مربوط يعرض المكوّن حالة عدم الربط، بلا نقاط أو مطاعم افتراضية.
إدارة دورة الخريطة مطلوبة عند الذهاب للسجل/الملف أو إنهاء الدوام أو فتح مهمة؛ لا تكرر المستمعين أو تحميل المكتبة. فحص lifecycle في المعاينة ليس فحص Leaflet حياً.


واجهة المراجعة مخطط غير جغرافي فقط؛ لا تنقل renderer المعاينة أو fixtures أو أرقامها إلى الإنتاج. احفظ تصحيحات v82b والمهام والمحادثة والخرائط الحالية، ولا تغير توزيع الطلبات أو الحسابات أو قاعدة البيانات.
