# كيفية عرض وتعديل وثائق TALABOT على GitHub (بالموبايل أو الكمبيوتر)

**المستودع الأساسي:** https://github.com/merapplications-sketch/Talabat-v3  
**فرع المراجعة الحالي:** `docs/owner-playbook-pilot-first-20261114`  
**الدليل:** [README](./README.md) • [القرارات الأصلية](./SOURCE-OF-TRUTH.md)  
**الملفات الجديدة مسودات مراجعة. لا تدمج `main` أو تغير الإنتاج من هذه الخطوات.**

## عرض الملفات من iPhone
1. افتح [فهرس الدليل مباشرة على فرع المراجعة](https://github.com/merapplications-sketch/Talabat-v3/blob/docs/owner-playbook-pilot-first-20261114/docs/owner-playbook/README.md).
2. اضغط اسم الملف المطلوب في الجدول. تظهر لك نسخة قابلة للقراءة، ويمكنك التصفح والبحث داخل الصفحة.
3. للتحقق من القرارات الملزمة افتح [Owner Agreements](../OWNER-AGREEMENTS-AR.md) و[Master #26](https://github.com/merapplications-sketch/Talabat-v3/issues/26). النصوص المقترحة لا تعدل هذه الموافقات.

## تعديل ملف واحد من متصفح GitHub
1. افتح الملف على **الفرع `docs/owner-playbook-pilot-first-20261114`**، لا `main`.
2. بعد تسجيل الدخول إلى حساب GitHub الذي يملك صلاحية التعديل، افتح قائمة `...` ثم **Edit file** أو رمز القلم (قد تحتاج وضع عرض سطح المكتب على Safari).
3. عدّل النص، ثم اختر **Commit changes**.
4. احفظ التعديل في **نفس فرع المراجعة**، أو أنشئ فرع مراجعة مشتقًا منه إذا عرض GitHub الخيار. لا تختَر `main` أو دمجًا تلقائيًا.
5. اكتب سبب التغيير في رسالة الـCommit. إذا كان يتصل بقاعدة معتمدة، اربط قرار المالك في تعليق Issue #26 بدل استبدال النص الأصلي.

## تعديل سياسة أو خطة جديدة
- أضف اقتراحك إلى ملف المسودات ذي الصلة، مع وسيلة التحقق ودليل التوافق مع المعتمد.
- لا تغير شيئًا في المستندات المعتمدة من تلقاء نفسك. التغيير في CASH-01/RETURN-01/PRICE/roles/design/release يحتاج موافقة مالك مستقلة.
- راجع تاريخ آخر التحديثات والتعليقات قبل إجراء تعديل حتى لا تستبدل عمل فريق آخر.
