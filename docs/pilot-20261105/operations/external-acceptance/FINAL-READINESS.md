## الدليل الجديد للمضيف

تمت قراءة أنواع المشروع الفعلية وإرشادات الأمان وفروع التطوير عبر أدوات المزوّد، دون أوامر SQL أو استدعاء RPC. [أنواع المضيف](HOST-TYPES.ts) وبصمتها ومقارنة أسماء الدوال في [HOST-CONTRACT-DIFF.json](HOST-CONTRACT-DIFF.json). من 97 دالة عامة معادة، تغيب 20 دالة من ملفات المرشح المقترحة، بينها `customer_confirm_order` و`order_return_action` و`finance_execute`. هذا يؤكد عدم التطابق مع دليل الجداول الخاص السابق. الفحص يخص أسماء الدوال ولا يدعي مقارنة الأجسام أو الصلاحيات كاملة.

[إرشادات المضيف](HOST-ADVISORS.json): 7 تحذيرات search_path غير مثبت، وتعطيل حماية كلمات المرور المسرّبة، و6 جداول RLS بلا سياسات مباشرة، وتحذيرات تنفيذ SECURITY DEFINER لـanon وauthenticated. ليست كلها ثغرات مثبتة: الدوال قد تحرس الدور داخلياً، وبعضها دوال triggers، ومنع السياسات المباشرة قد يكون مقصوداً. يلزم حسمها من تعريفات الإعدادات والدوال؛ لم نغيّر صلاحيات أو ندّع ثغرة قابلة للاستغلال. روابط المعالجة الرسمية محفوظة بكل finding. لم تُعد أداة الفروع أي هدف تطوير للمشروع.
