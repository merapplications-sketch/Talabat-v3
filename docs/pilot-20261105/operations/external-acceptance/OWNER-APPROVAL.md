# ورقة اعتماد خيار بلا مقدم — غير معتمدة

المطلوب اعتماد نموذج العمل فقط؛ اعتماد هذه الورقة لا يجيز تفعيل التجربة أو نشرها أو تحريك الأموال. التوصية: مطاعم توافق على تسليم الوجبة على ذمة TALABOT دون دفع السائق، مع تسوية المستحقات بعد مصالحة الوردية. التنفيذ الحالي لا يدعم الانطلاق بصفر؛ نتيجة الرفض محفوظة ولا تحتاج إعادة.

سجل الطلب يربط الاتفاق بإجمالي الوجبة المعتمد وإثبات استلامها، ويثبت مقدم السائق صفراً. عند التسليم يسجل المقبوض الفعلي من الزبون ومرجعه وعهدة السائق، منفصلاً عن مستحق المطعم وأجرة السائق. تعالج فروق المبلغ والردود والائتمان بوثائق مستقلة، ولا يغلق الطلب المالي بوجود فرق غير محسوم. لا تُحفظ التواقيع أو بيانات الحسابات في المستودع العام.

قبل اعتماد النموذج يمكن مراجعة هذه الوثيقة والأدلة الحالية وإكمال فحوص القناة والبريد والأجهزة عند توفيرها. اختبار رحلة بلا مقدم مكتملة يتوقف على اعتماد العقد وتنفيذ مساره؛ لا نعيد تسمية المسار الحالي أو نمرره بمبلغ وهمي.
