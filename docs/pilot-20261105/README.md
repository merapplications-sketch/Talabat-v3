## النتائج السابقة المحفوظة


- استعادة كلمة المرور بالواجهات الحالية، مع رابط يرجع للتطبيق نفسه ومنع علامة recovery غير الموثوقة من استهداف جلسة قائمة. **10 نقاط** عبر Chrome156 وGoTrue/SMTP محليين نجحت، و**4 نقاط** مستقلة لتأكيد التسجيل بالبريد محفوظة.
- **18 فحصاً** ناجحاً على Safari27.2 أصلي في macOS15.8.2، مع التنسيق الأصلي وصورة دليل. العقد الخلفي هناك اصطناعي معلن؛ لا يساوي Safari على آيفون أو ربطه بالمضيف الحقيقي.
- Storage API فعلي: **12 نقطة** لعزل الرفع والقراءة والرابط العام والمؤقت ومنع الاستبدال؛ ثم **3 نقاط** لاستعادة metadata وملف الصورة الفعلي وبقاء العزل.
- إصلاح عيب مثبت بالمصدر المعزول: كان التسليم يقبل مسار صورة غير موجودة. الرقعة المقترحة تتحقق من الكائن المحفوظ وتقفل metadata قبل التسليم. **4 فحوص متأثرة** نجحت بلا أثر جزئي، وفحص إضافي أثبت بقاء التسليم العادي دون صورة صالحاً قبل وجود مخطط Storage. [آخر تشغيل ناجح](https://github.com/merapplications-sketch/Talabat-v3/actions/runs/42041037080).
- حمل مطابق لاستعلامات التطبيق: **180 ثانية،18 رحلة مكتملة،384 HTTP،صفر أخطاء أو تكرار،p95=67.67ms وp99=137.61ms**، مع3رحلات متزامنة و8جلسات متابعة وتاريخ10000طلب. لا ضمان سعة حية أو تحمل ساعات من هذا القياس.
- مسح تاريخ318commit و2192blob، بلا مرشح ضمن أنماط الأسرار المفحوصة؛ لا يشمل أسرار المزود أو فك الأرشيفات، ولم تستخدم مفاتيح للتحقق منها خارجياً.
