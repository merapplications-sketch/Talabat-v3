**لا تبدأ تجربة حقيقية الآن.** أُنجزت إصلاحات واختبارات معزولة جديدة، لكن قرار موافقة أول كاش وتأكيد التغييرات لم يدخل بعد مسار الطلب بالخادم والواجهتين، ومسار إرجاع مال السائق والمطالبة بالمتبقي ما زال للمراجعة وغير منفذ. هذه موانع تنفيذ فعلية، إضافة إلى موانع الأجهزة والمضيف والتشغيل؛ هذا ليس إغلاقاً شاملاً لتكليف الإطلاق.

الفرع: `candidate/pilot-readiness-20261105`. مصدر الإصلاح المختبر: **`6a8dc917be1981db84a894b855868f9e154be68d`**. المنشور بحسب آخر مطابقة HTTP محفوظة: `ca8808dd6dee4f4815a266ae9bb9ea20a155f892`. لا نشر جديد. إغلاق التزامن **`b30105bab2a3bfbc6764b17d620f4e6ad1a963b9`** ثابت، ولم تعد فحوص53 أو حالات التزامن10 غير المتأثرة.

## ما نُفذ واختبر في الاستكمال

- استعادة كلمة المرور بالواجهات الحالية، مع رابط يرجع للتطبيق نفسه ومنع علامة recovery غير الموثوقة من استهداف جلسة قائمة. **10 نقاط** عبر Chrome156 وGoTrue/SMTP محليين نجحت، و**4 نقاط** مستقلة لتأكيد التسجيل بالبريد محفوظة.
- **18 فحصاً** ناجحاً على Safari27.2 أصلي في macOS15.8.2، مع التنسيق الأصلي وصورة دليل. العقد الخلفي هناك اصطناعي معلن؛ لا يساوي Safari على آيفون أو ربطه بالمضيف الحقيقي.
- Storage API فعلي: **12 نقطة** لعزل الرفع والقراءة والرابط العام والمؤقت ومنع الاستبدال؛ ثم **3 نقاط** لاستعادة metadata وملف الصورة الفعلي وبقاء العزل.
- إصلاح عيب مثبت بالمصدر المعزول: كان التسليم يقبل مسار صورة غير موجودة. الرقعة المقترحة تتحقق من الكائن المحفوظ وتقفل metadata قبل التسليم. **4 فحوص متأثرة** نجحت بلا أثر جزئي، وفحص إضافي أثبت بقاء التسليم العادي دون صورة صالحاً قبل وجود مخطط Storage. [آخر تشغيل ناجح](https://github.com/merapplications-sketch/Talabat-v3/actions/runs/42041037080).
- حمل مطابق لاستعلامات التطبيق: **180 ثانية،18 رحلة مكتملة،384 HTTP،صفر أخطاء أو تكرار،p95=67.67ms وp99=137.61ms**، مع3رحلات متزامنة و8جلسات متابعة وتاريخ10000طلب. لا ضمان سعة حية أو تحمل ساعات من هذا القياس.
- مسح تاريخ318commit و2192blob، بلا مرشح ضمن أنماط الأسرار المفحوصة؛ لا يشمل أسرار المزود أو فك الأرشيفات، ولم تستخدم مفاتيح للتحقق منها خارجياً.

## قرارات المالك وحالتها

[قرار أول كاش المعتمد](followup/FIRST-CASH-CONFIRMATION.md): بعد تأكيد المطعم التوفر ووقت التجهيز يظهر الإجمالي والعنوان والوقت وزر **«أكّد وابدأ التحضير»**؛ لا تحضير أو دفع سائق قبل موافقة الزبون. الطلب التالي بلا تغيير يكتفي بتأكيد الدفع، والتغييرات تحتاج قبولاً. **التنفيذ غير مكتمل، والقرار ليس ميزة موجودة لمجرد حفظه.** المهلة وتعريف التأخير المؤثر مفتوحان؛ الدقيقتان اقتراح والصمت لا يوافق.

[سياسة الإلغاء ومسار المراجعة](followup/CANCELLATION-POLICY-REVIEW.md): المطعم الموافق مسبقاً يستلم الوجبة ويرد المدفوع فعلياً، والمنصة تتحمل أجرة التوصيل. الاستلام ورد المال والاستحقاق أحداث منفصلة. الرد الجزئي أو الرفض يبقي مطالبة السائق بالمتبقي؛ لا يعتبر رصيد الكاش الصفري سداداً لها. مسؤولية الزبون لا تعمم على خطأ المطعم أو السائق أو المنصة.

القرارات المفتوحة مجمعة: أجرة الرجوع، تعذر الإرجاع، رفض/رد جزئي من المطعم، عدم حضور الزبون، مهلة رد الزبون، وتعريف التأخير المؤثر. لا مبلغ أو إجراء أو موافقة تلقائية مفترضة.

## الموانع بالترتيب

1. تنفيذ وقبول موافقة أول كاش ونسخ التغييرات بالخادم والواجهتين، ثم مسار الإرجاع والمطالبات وفق السياسة واتفاق المطعم. لا تشغيل لدفع السائق من جيبه قبل ذلك.
2. مطابقة إعداد المضيف وSQL وAuth/SMTP/Realtime/Storage والصلاحيات والنسخ الحقيقية، دون SQL حي في هذا التكليف. قراءة المستشار السابقة أبلغت hibernation ولم ننفذ wake؛ إعداد Auth الكامل غير متاح عبر أدوات الاتصال الحالية.
3. قبول iPhone/Safari وAndroid الفعليين، الكاميرا والموقع والخلفية والطباعة. يتولاه الفريق دون تكليف المالك بجمع سجلات تقنية. لا أجهزة فعلية أو حزم متجر أو توقيع متاح هنا.
4. مناوب وبديل وقناة تنبيه مجدولة تصل إليهما، ونسخة خارجية واستعادة حقيقية، وحصر تقني للمشاركين والمنطقة والدوام والسقف. watchdog المحفوظ outbox غير مفعل. إشعارات الخلفية ناقصة بالمصدر.
5. بيانات المحاسب الحقيقية ثم موافقة تفعيل محددة لاحقاً. «محاسب TALABOT» اسم مؤقت معتمد؛ لا حساب بديل أو تفويض الآن.
