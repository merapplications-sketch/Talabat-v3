# حفظ ربط الإصلاحات التاريخية

أُنشئ `LEGACY-REGRESSION-INDEX.json` وفيه13سجلاً تشمل SEC-001 إلىSEC-004، تعطيل الحساب، إلغاء الجلسة، حواجزRPC، مساحة جلسة المحاسب، إصلاح صلاحية المحاسب F21-01، روابط الإثبات، CSP، معرّف الطلب F22-01 وخمول الإدارة.

لكل سجل: السبب والمسارات، الدليل السلبي والإيجابي المحفوظ، ملفات الأدلة وبصماتها، اختباره المحلي الحالي إن وجد، وفجوة التحقق الحي. لم تُعد الفحوص ولم يُغيّر التطبيق أو المزوّد أو البيانات.

حقول أول commit للإصلاح بقيت `null` عندما لم يثبت commit الإضافة الأول من التاريخ. الـcommits المذكورة هي نقاط مصدر/أدلة معروفة من التقارير، وليست نسباً افتراضياً لأول إصلاح. معرفات ترحيلات قاعدة البيانات مستقلة عن نشر الواجهة. أسماء `LEGACY-*` مفاتيح جرد جديدة وليست أرقام ثغرات تاريخية مُدّعاة.

أُبقي الفصل بين إصلاح مساحة جلسة المحاسب وإصلاح صلاحية finance الداخلية. كما أُبقي فشل الرابط الموقّع القديم بعد الحظر منفصلاً عن نجاح منع إصدار روابط جديدة. لا يُغلق هذا الجرد V7.4.2 أو MFA أو أي متطلب ASVS كاملاً؛ ولا يجعل إثبات SQL أو الاختبار المحلي بديلاً عن إعادة تحقق حي عند تغير الجزء المتصل به.
