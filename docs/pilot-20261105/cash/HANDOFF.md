## طريقة تجربة واحدة

من نسخة نظيفة من الفرع وعلى جهاز عليه Docker Compose وPython3/venv وNode/npm:

```bash
bash tests/pilot/cash/run.sh
```

افتح `http://127.0.0.1:8080`: واجهات التطبيق الأصلية وحسابات وهمية معزولة. افتح الإدارة والمحاسب في ملفي متصفح منفصلين. الوجبة DEMO dish بقيمة25، التوصيل15، العنوان DEMO Rudaki1 والإحداثيات38.5598 و68.787. المطعم يراجع والزبون يؤكد، الإدارة تعين السائق المتصل، المطعم يجهز، السائق يستلم ويوثق دفع25 من سجل الإرجاع بمرجع مختلف لكل طلب (DEMO-PAY-1 ثم DEMO-PAY-2) ثم يؤكد قبض40 والتسليم. المحاسب يسجل استلام5 فقط بعد استلامه الافتراضي.

قبل الطلب الثاني شغّل في طرفية المعمل `python tests/pilot/cash/policy.py 0` باستخدام Python بيئته `tests/pilot/cash/.venv/bin/python` إذا لم تكن مفعلة. كرر الرحلة: يحتفظ السائق40 ولا يُطلب تسليم للمحاسب. هذا الأمر يغيّر سياسة المعمل وحده ولا يغيّر الطلب الأول. تحديث الصفحة بين الأدوار يعوض غياب خدمة Realtime في المعمل. Ctrl+C يحذف البيئة المحلية؛ لا تستخدم بيانات حقيقية. الحسابات والاتفاقات التركيبية محدودة بساعتين.
