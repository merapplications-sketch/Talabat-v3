# تشغيل حزم المعمل لاحقاً

ملفات الاختبارات القديمة باقية؛ الحزم السابقة قابلة للاختيار بدلاً من `if: false`. لا تشغّل دفعة الوثائق الحزم الناجحة تلقائياً. لكل تشغيل قاعدة مؤقتة وبيانات اصطناعية وإزالة للحاويات بعده. لا مفاتيح نشر أو اتصال بخادم TALABOT الحي.

على فرع المرشح، عنوان commit مقصود مثل `test(pilot): run consent-server` يشغّل تلك الحزمة فقط، بما في ذلك إذا لم يوجد تعريف workflow في الفرع الافتراضي بعد. اختيار `workflow_dispatch` متاح عند توفر تعريفه في الفرع الافتراضي. الخيارات الرسمية في [تعريف الحزم](../../../.github/workflows/pilot-isolated.yml).

- **عقد ما قبل الموافقة:** `journey`، `driver-ui`، `load`، `backup`، `soak`، `smtp`، `storage`. المعمل لا يطبق رقعتي الموافقة والحصر عند اختيار هذه العقود التاريخية. لا تعد تلك نتيجة للمرشح الكامل.
- **الموافقة دون قيد المشاركين:** `consent-server`، `consent-ui`، `consent-ui-edges`، `consent-compat`، `legacy-ui`، `consent-load`. يحتفظ كل منها بالسيناريو المعزول المقصود.
- **الحزمة الكاملة:** `admission`، `admission-load`، `consent-backup`، `timing`، `admission-dispatch`. لا تضبط قيم الاختبار أو المشاركين حياً.
- **Safari المكتبي:** `test(safari): run consent` للمكونات، و`test(safari): run summary` لملخص الطلب. فحص Safari المكتبي السابق مستقل ولم يتغير.

هذه الجولة تحققت من اختيار الحزم وشغلت `admission-dispatch` فقط. الأدلة القديمة محفوظة كمخرجات التشغيل الأصلي، وليست ادعاء إعادة اختبار كامل الحزمة على أحدث SHA.
